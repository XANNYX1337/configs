# CFG Workshop

Сайт-каталог конфигов для [XANNYX1337/configs](https://github.com/XANNYX1337/configs). Любой может загрузить свой `.cfg` с описанием, скачать конфиги и скопировать ссылку для Discord.

## Функции

- **Добавить конфиг** — загрузка одного или нескольких файлов с расширением `.cfg` (другие отклоняются), поле описания (игра/стиль/автор).
- **Список конфигов** — автоматически подтягивается из папки `configs/` (включая вложенные папки), с описаниями и датой загрузки.
- **Скачать / Ссылка** — прямая ссылка на файл для Discord.
- Обновление списка кнопкой «Обновить».

## Как это устроено

- Сайт статичный на GitHub Pages, бэкенда нет.
- Всё работает через GitHub API из браузера.
- Файлы лежат в папке `configs/`, описания — в `configs.json` в корне репозитория.

## Настройка загрузок (токен)

Для загрузки конфигов нужен GitHub-токен. Он вставляется в `app.js` в блок `CONFIG`, поле `token`:

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `configs`.
3. Repository permissions → **Contents: Read and write**.
4. Создайте токен и вставьте его в `app.js`, затем запушите.

⚠️ Токен виден в исходном коде страницы — не выдавайте ему прав больше, чем на репозиторий конфигов.

## Публикация сайта

Репозиторий `configs` — одновременно и хранилище конфигов, и хостинг сайта: файлы сайта (`index.html`, `style.css`, `app.js`) лежат в корне, конфиги — в `configs/`.

- GitHub Pages: репозиторий → Settings → Pages → Deploy from a branch → `main` → Save.
- Сайт: `https://xannyx1337.github.io/configs`

## Ограничения

- GitHub API без токена: 60 запросов/час на чтение (список). Загрузка всегда через токен.
- Файлы до 100 МБ (лимит GitHub).
